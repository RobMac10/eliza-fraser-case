# Eliza Fraser and the wreck of the Stirling Castle

A classroom case file from *Reopen the Record: Australian Histories*.

The question is: was Eliza Fraser a captive, or a guest? The opener is *Letter from the longboat*, in the voice of C. Brown, early July 1836.

This investigation acknowledges the Butchulla Aboriginal Corporation, the RNTBC for K’gari, and with the families or Elders the Corporation names. Open `index.html` in a browser, or serve the folder with any static server.

The letter is written to look authentic. What’s true about it sits only in the teacher notes. Silhouettes are plain name cards, not likenesses. Words in quotation marks come from a named record.
