# Eliza Fraser and the wreck of the Stirling Castle

A draft classroom case file (Year 9) from *Reopen the Record: Australian Histories*.

The question is: was Eliza Fraser a captive, or a guest? The opener is *Letter from the longboat*, in the voice of C. Brown, early July 1836.

**This site is a draft.** It is pending consultation with the Butchulla Aboriginal Corporation, the RNTBC for K’gari, and with the families or Elders the Corporation names. It is not a finished student file, and it has not been published.

Open `index.html` in a browser, or serve the folder with any static server.

The letter is written to look authentic. What’s true about it sits only in the teacher notes. Silhouettes are plain name cards, not likenesses. Words in quotation marks come from a named record.
